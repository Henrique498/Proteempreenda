FAQ

Perguntas frequentes

Posso cancelar a qualquer momento? +
Sim. Não há fidelidade. Você pode cancelar sua assinatura a qualquer momento sem multa ou burocracia. Seu acesso continua até o fim do período pago.
A criança sabe que está sendo monitorada? +
Sim, conforme exigido pela Lei 15.211/2025. O GuardianNet é transparente e informa a criança que o monitoramento está ativo. Não somos uma ferramenta de espionagem — somos uma ferramenta de proteção com consentimento.
Como os dados das conversas são armazenados? +
Apenas os alertas e metadados necessários são armazenados. O conteúdo completo das conversas não é guardado além do necessário para análise. Todos os dados são criptografados e seguem a LGPD.
O sistema analisa todos os aplicativos? +
Na versão atual (MVP), a análise é feita manualmente ou via integração com aplicativos específicos. A versão completa do app mobile terá integração nativa com WhatsApp, Instagram, Telegram e outros.
Tem desconto para múltiplas crianças? +
O plano Premium já inclui crianças ilimitadas no mesmo preço. Não há cobrança adicional por criança no plano familiar.
