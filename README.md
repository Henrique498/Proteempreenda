# 🚀 Proteempreenda

Uma API desenvolvida em Python com Flask para apoiar e impulsionar o empreendedorismo, integrando recursos de tradução e aprendizado de máquina em tempo real.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias e bibliotecas:

* **[Python](https://www.python.org/)** — Linguagem principal
* **[Flask](https://flask.palletsprojects.com/)** — Microframework web para criação da API
* **[Flask-CORS](https://flask-cors.readthedocs.io/)** — Manipulação de CORS (Cross-Origin Resource Sharing)
* **[Psycopg2-binary](https://pypi.org/project/psycopg2-binary/)** — Adaptador de banco de dados PostgreSQL para Python
* **[Python-dotenv](https://pypi.org/project/python-dotenv/)** — Gerenciamento de variáveis de ambiente
* **[Werkzeug](https://werkzeug.palletsprojects.com/)** — Utilitários WSGI e funções de segurança (hashing de senhas, etc.)
* **[Gunicorn](https://gunicorn.org/)** — Servidor HTTP WSGI para ambiente de produção
* **[River](https://riverml.xyz/)** — Biblioteca para Aprendizado de Máquina Online (Machine Learning em tempo real)
* **[Deep-Translator](https://pypi.org/project/deep-translator/)** — Ferramenta flexível para tradução de textos entre múltiplos idiomas

---

Antes de começar, você precisará ter instalado em sua máquina:
